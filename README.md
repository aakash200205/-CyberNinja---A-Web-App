# Project Overview

The project was designed using an **MVC framework**, employing a full-stack approach with the following technologies:

- **Front-end**: HTML, CSS, JavaScript  
- **Back-end**: Node.js, Express.js  
- **Database**: MongoDB  

This project skillfully integrated secure and dynamic web functionalities, showcasing:  
- A strong understanding of both **front-end** and **back-end development**.  
- An aptitude for building efficient, user-friendly applications.
